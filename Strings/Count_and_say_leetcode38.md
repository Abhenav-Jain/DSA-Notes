# LeetCode 38 — Count and Say

**Pattern:** Recursion + String Simulation + Consecutive Group Counting  
**Difficulty:** Medium  
**Approach:** Top-Down Recursion  
**Language:** C++

---

## 1. Problem Understanding

We are given an integer `n`.

We need to generate the nth term of the Count and Say sequence.

The sequence starts with:

```text
Term 1 = "1"
```

Each subsequent term is generated by reading the previous term and describing consecutive groups of identical digits.

For every group:
1. Count the number of consecutive occurrences.
2. Write the count.
3. Write the digit itself.

### Sequence

| n | Count and Say Term |
|---:|---|
| 1 | `"1"` |
| 2 | `"11"` |
| 3 | `"21"` |
| 4 | `"1211"` |
| 5 | `"111221"` |
| 6 | `"312211"` |

### Important Observation

This is not normal numerical counting.

We are describing the previous string, not performing arithmetic on its numeric value.

For example:

```text
"111" → "31"
```

Explanation:
- Three consecutive `1`s.
- Write `3` followed by `1`.
- Result = `"31"`.

---

## 2. Core Intuition

The key observation is:

**To generate the nth term, we only need the (n-1)th term.**

Therefore, recursion is a natural approach.

Our recursive function follows three steps:

1. Base Case: If `n == 1`, return `"1"`.
2. Recursive Call: Generate the previous term using `countAndSay(n-1)`.
3. Processing: Traverse the previous term, count consecutive identical characters, and construct the current result.

### Recursion Relationship

```text
countAndSay(5)
    |
    └── countAndSay(4)
            |
            └── countAndSay(3)
                    |
                    └── countAndSay(2)
                            |
                            └── countAndSay(1)
                                    |
                                    └── "1"
```

Once the base case returns, the recursive calls start processing in reverse order.

## 3. Accepted C++ Implementation

```cpp
class Solution {
public:
    string countAndSay(int n) {

        // Base Case
        if(n == 1) {
            return "1";
        }

        // Generate previous term
        string say = countAndSay(n-1);

        // Construct current term
        string result;

        // Process consecutive groups
        for(int i = 0; i < say.length(); i++) {

            char ch = say[i];
            int count = 1;

            while(i < say.length()-1 && ch == say[i+1]) {
                count++;
                i++;
            }

            result += to_string(count) + string(1, ch);
        }

        return result;
    }
};
```

---

## 4. Detailed Code Explanation

### Step 1: Base Case

```cpp
if(n == 1) {
    return "1";
}
```

The first term of the sequence is always `"1"`.

This condition terminates recursion.

Without a base case, recursive calls would continue indefinitely.

### Step 2: Recursive Call

```cpp
string say = countAndSay(n-1);
```

We generate the previous term before constructing the current one.

For example:

```text
countAndSay(4)
```

First generates:

```text
countAndSay(3) = "21"
```

Then processes `"21"` to generate `"1211"`.

### Step 3: Initialize Result

```cpp
string result;
```

This string stores the newly generated term.

### Step 4: Traverse the Previous Term

```cpp
for(int i = 0; i < say.length(); i++) {
    char ch = say[i];
    int count = 1;
}
```

- `i` traverses the previous string.
- `ch` stores the current character.
- `count = 1` because the current character itself is already counted.

### Step 5: Count Consecutive Identical Characters

```cpp
while(i < say.length()-1 && ch == say[i+1]) {
    count++;
    i++;
}
```

This is the most important part of the solution.

We check:
1. Whether the next index exists.
2. Whether the next character matches the current character.

If both conditions are true:
- Increment the count.
- Move `i` forward.

The loop ends when a different character is found or the string ends.

**Important:** After the inner loop, `i` points to the last character of the current group.

The next iteration of the outer loop automatically moves to the next group.

### Step 6: Construct the New Term

```cpp
result += to_string(count) + string(1, ch);
```

We append:

```text
Count + Character
```

Why `to_string(count)`?

Because the count is an integer, but our result is a string.

Why `string(1, ch)`?

Because it converts one character into a string containing exactly one character.

Example:

```cpp
count = 3;
ch = '1';
```

Then:

```text
to_string(count) = "3"
string(1, ch)    = "1"

Appended result  = "31"
```

### Step 7: Return Result

```cpp
return result;
```

After processing all groups, the newly generated term is returned.

## 5. Complete Dry Run — n = 5

We want:

```text
countAndSay(5)
```

### Phase 1: Recursive Calls

```text
countAndSay(5)
    → countAndSay(4)
        → countAndSay(3)
            → countAndSay(2)
                → countAndSay(1)
```

Base case:

```text
countAndSay(1) = "1"
```

Now recursion starts unwinding.

### Phase 2: Generate Term 2

Previous term:

```text
"1"
```

Groups:

| Character | Count | Output |
|---|---:|---|
| 1 | 1 | 11 |

Therefore:

```text
Term 2 = "11"
```

### Phase 3: Generate Term 3

Previous term:

```text
"11"
```

Groups:

| Character | Count | Output |
|---|---:|---|
| 1 | 2 | 21 |

Therefore:

```text
Term 3 = "21"
```

### Phase 4: Generate Term 4

Previous term:

```text
"21"
```

Groups:

| Character | Count | Output |
|---|---:|---|
| 2 | 1 | 12 |
| 1 | 1 | 11 |

Therefore:

```text
Term 4 = "1211"
```

### Phase 5: Generate Term 5

Previous term:

```text
"1211"
```

Now process character groups.

**Group 1:**

```text
ch = '1'
count = 1
```

Next character is different.

Append:

```text
"11"
```

**Group 2:**

```text
ch = '2'
count = 1
```

Next character is different.

Append:

```text
"12"
```

**Group 3:**

```text
ch = '1'
count = 2
```

Two consecutive `1`s are found.

Append:

```text
"21"
```

Final result:

```text
"11" + "12" + "21"

= "111221"
```

Therefore:

```text
countAndSay(5) = "111221"
```

## 6. Recursion Tree vs Processing

A common interview confusion is understanding when the actual string processing happens.

Consider:

```cpp
string say = countAndSay(n-1);
```

The current function cannot process its string until the recursive call returns.

For `n = 4`:

```text
Call countAndSay(4)
    Call countAndSay(3)
        Call countAndSay(2)
            Call countAndSay(1)
                Return "1"

            Process "1"
            Return "11"

        Process "11"
        Return "21"

    Process "21"
    Return "1211"
```

**Remember:** Recursive calls go downward; processing happens while recursion unwinds.

---

## 7. Pointer Movement — Important Detail

Consider:

```text
say = "1211"
```

Initial:

```text
i = 0
```

| Iteration | Current character | Count | i after group |
|---|---|---:|---:|
| 1 | 1 | 1 | 0 |
| 2 | 2 | 1 | 1 |
| 3 | 1 | 2 | 3 |

Why does the third group finish at `i = 3`?

Because the inner loop increments `i` when it consumes the second consecutive `1`.

When the outer `for` loop increments `i`, it becomes `4` and terminates.

This avoids processing the same character twice.

## 8. Complexity Analysis

Let `L(k)` denote the length of the kth generated term.

Each recursive call processes the previous term.

Therefore:

```text
T(n) = T(n-1) + O(L(n-1))
```

Expanding:

```text
T(n) = O(L(1) + L(2) + ... + L(n-1))
```

**Time Complexity:**

```text
O(Σ L(k)), for k = 1 to n-1
```

This is more precise than simply claiming O(n), because the generated strings grow in length.

**Auxiliary Space:**

- Recursive call stack: O(n).
- Intermediate strings: previous and current generated terms.
- Output storage: proportional to the generated string length.

A precise peak-space description is O(n + L(n)), considering the recursive stack and simultaneously retained intermediate strings.

## 9. Common Interview Mistakes

### Mistake 1: Incorrect Base Case

Incorrect:

```cpp
if(n == 0) return "1";
```

Correct:

```cpp
if(n == 1) return "1";
```

### Mistake 2: Starting Count From Zero

Incorrect:

```cpp
int count = 0;
```

Correct:

```cpp
int count = 1;
```

The current character is already part of the group.

### Mistake 3: Forgetting to Increment i

If `i` is not incremented inside the inner loop, already-counted characters may be processed again.

### Mistake 4: Incorrect Boundary Check

Always check that the next index exists before accessing `say[i+1]`.

```cpp
i < say.length()-1
```

### Mistake 5: Treating the Sequence as a Number

The terms are strings. We are describing consecutive character groups, not performing numerical operations.

### Mistake 6: Appending Count Incorrectly

The count must be converted into a string.

```cpp
to_string(count)
```

Also, the character must be appended after the count.

## 10. Alternative Iterative Approach

The same problem can be solved without recursion.

Start with `"1"` and repeatedly generate the next term until we reach `n`.

```cpp
class Solution {
public:
    string countAndSay(int n) {

        string say = "1";

        for(int step = 2; step <= n; step++) {

            string result;

            for(int i = 0; i < say.length(); i++) {

                char ch = say[i];
                int count = 1;

                while(i < say.length()-1 && say[i+1] == ch) {
                    count++;
                    i++;
                }

                result += to_string(count) + string(1, ch);
            }

            say = result;
        }

        return say;
    }
};
```

### Recursive vs Iterative

| Feature | Recursive | Iterative |
|---|---|---|
| Starting point | Base case | Initial string `"1"` |
| Generation | Recursive call | Loop |
| Processing | During recursion unwind | Inside loop |
| Call stack | O(n) | O(1) |
| String processing | Same | Same |

Both approaches generate the same sequence.

The iterative approach avoids recursive stack usage.

## 11. Interview Follow-up Questions

**Q1. Why is recursion suitable here?**

Because every term depends directly on the previous term.

**Q2. What is the base case?**

The first term is always `"1"`.

**Q3. What does the inner while loop do?**

It counts consecutive occurrences of the same character.

**Q4. Why do we increment i inside the inner loop?**

To consume all characters belonging to the current group and avoid processing them again.

**Q5. Why do we use `string(1, ch)`?**

To convert a single character into a string before concatenation.

**Q6. Can the count contain multiple digits?**

Yes. For a group of ten identical characters, we append `"10"` followed by the character.

**Q7. Is this a Run Length Encoding problem?**

It uses the same basic idea of grouping consecutive identical characters and encoding their counts. However, Count and Say repeatedly applies this transformation to generate a sequence.

**Q8. What is the difference between recursion and iteration here?**

Both use the same group-processing logic. Recursion relies on the call stack, while iteration uses a loop to generate each term.
